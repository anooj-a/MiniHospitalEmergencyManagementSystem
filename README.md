# Mini Hospital Emergency Management System Using Data Structures

Console-based Java model for a CIT-300 Data Structures and Algorithms(2) Individual Mid Assignment .

## Data Structures

1. **Binary Search Tree (BST)** - patient records keyed by Patient ID.
   - Insert
   - Search
   - Delete
   - In-order display

2. **Queue** - emergency patients.
   - Enqueue
   - Dequeue
   - Display
   - FIFO behavior
   - Empty queue handling

3. **Stack** - completed treatment records.
   - Push
   - Pop
   - Display
   - LIFO behavior
   - Empty stack handling

4. **Singly Linked List** - each patient's visit history.
   - Add visit
   - Search visit
   - Remove visit
   - Display visits

## Project Structure

All Java source files are in `src/`.

## Compile and Run

From the project directory:

```text
javac src/*.java
java -cp src Main
```
